## Pre-Deployment Checklist

### Backend Setup
- [ ] Add your GROQ_API_KEY to environment variables
- [ ] Test backend locally: python app.py
- [ ] Update CORS origins with your frontend URL
- [ ] Push code to GitHub repository

### Frontend Setup
- [ ] Update API endpoints in config.js
- [ ] Test frontend with local backend
- [ ] Update API endpoints for production

### Deployment Steps
- [ ] Deploy backend to Vercel/Render
- [ ] Get production backend URL
- [ ] Update frontend config with production URL
- [ ] Deploy frontend to Vercel
- [ ] Test complete application

### Post-Deployment
- [ ] Test all chatbot functions
- [ ] Verify file uploads work
- [ ] Check CORS issues
- [ ] Monitor application logs
